# KI-26 The build pins no SushiRuntime version

The row of this entry is in `docs/backlog/CONTINUOUS_INTEGRATION.md`. This file holds what did not fit the row.

- Origin: own
- Where: `cmake/Runtime.cmake`, `cmake/SushiBLASConfig.cmake.in`, `.github/workflows/ci.yml`
- Cause: `find_package(SushiRuntime QUIET)` and `find_dependency(SushiRuntime)` name none, and CI checks out the runtime's default branch
- Recognise: the build breaks when the runtime's default branch drops `Runtime::buffer` with an alignment, `Recorder::task` or `Graph::plan()`
- Workaround: check out a runtime commit that carries them
