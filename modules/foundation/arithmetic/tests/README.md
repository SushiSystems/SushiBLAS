# Tests of arithmetic

The unit tests of the `arithmetic` module, built into `sushiblas_arithmetic_tests` by the module's `CMakeLists.txt`. The source comments state what a test checks. `tests/unit/README.md` holds the reasoning the tests share, and `tests/common/README.md` describes the fixtures.

| File | Tests |
| --- | --- |
| `test_complex_arithmetic.cpp` | Tests the conjugation, product and quotient bricks on real and complex values |
